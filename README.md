# КТК Расписание - iOS App

Неофициальное приложение для Курганского Технологического Колледжа, работающее с системой education-system.ru.

## Особенности

- 📅 **Расписание занятий** - личное, групповое и преподавательское
- 📝 **Домашние задания** - просмотр заданий, файлов и дедлайнов
- 🎥 **Вебинары** - ссылки на онлайн-занятия
- 🔐 **Безопасная авторизация** - хранение учетных данных в Keychain
- 🌙 **Тёмная тема** - поддержка системной и принудительной тёмной/светлой темы
- 📱 **Современный UI** - SwiftUI, нативный опыт iOS 16+

## Архитектура

Приложение построено на основе реверс-инжениринга API системы education-system.ru, используя в качестве референса проект [ktk-schedule](https://github.com/kurumihere/ktk-schedule) (Rust).

### Основные компоненты

```
KTKApp/
├── Configuration/       # Конфигурация API и константы
├── Models/              # Модели данных (расписание, пользователь, сессия)
├── Network/             # API клиент (Alamofire + серверные функции)
├── Storage/             # Keychain + UserDefaults менеджеры
├── ViewModels/          # MVVM view models
├── Views/               # SwiftUI экраны
└── Extensions/          # Расширения Foundation
```

### Авторизация (Digital Platform)

Сайт использует **TanStack Start** с **seroval** сериализацией. Авторизация происходит через server function:

```
POST /_serverFn/9cd5b48fd0588913cb64c83d8ae2b42d5f3e97ed5dd47dc10f211cdc2322c1f6
{
  "collegeId": "18902",
  "password": "hv@%20fv",
  "fingerprint": "sha256(login + device)[:32]"
}
```

Fingerprint генерируется как первые 16 байт SHA-256 от конкатенации логина и идентификатора устройства.

### API Endpoints

Основные server functions (могут меняться при редеплое):
- `signIn` - авторизация
- `studentSchedule` - расписание студента
- `teacherSchedule` - расписание преподавателя
- `groupSchedule` - расписание группы
- `studentHomework` / `groupHomework` - домашние задания
- `studentWebinar` / `groupWebinar` - вебинары
- `logout` - выход

## Установка и запуск

### Через Xcode

1. Откройте `KTKApp.xcodeproj` в Xcode
2. Выберите целевое устройство/симулятор
3. Нажмите `Cmd+R` для запуска

### Через Swift Package Manager

```bash
cd KTKApp
swift build
```

### Зависимости

Зависимости управляются через `Package.swift`. При открытии в Xcode они загрузятся автоматически.

## Использование

1. При первом запуске введите ваш номер студенческого/преподавателя и пароль
2. Включите "Запомнить меня" для автоматического входа через Keychain
3. Переключайте недели свайпами или кнопками навигации
4. Выбирайте область: "Личное" или "Группа N"
5. Нажмите на занятие с домашним заданием для просмотра деталей

## Настройки

В разделе "Настройки" доступно:
- Выбор темы (Системная/Светлая/Тёмная)
- Фильтр по подгруппе
- Автообновление расписания
- Уведомления
- Очистка кэша
- Обновление адресов API (при изменении эндпоинтов на сервере)
- Выход / Забыть аккаунт

## Известные ограничения

- Эндпоинты server functions могут меняться при редеплое сайта (приложение пытается их переоткрыть автоматически)
- Пароль хранится в Keychain только при включенной опции "Запомнить меня"
- Некоторые функции (звонки, типы пар, аудитории) требуют дополнительной реализации discovery

## Безопасность

- Все сетевые запросы идут только на `ktk.education-system.ru` (ATS configured)
- Учетные данные хранятся в iOS Keychain с `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`
- Сессионные куки сохраняются в HTTPCookieStorage
- Пароль НЕ сохраняется в UserDefaults или логах
